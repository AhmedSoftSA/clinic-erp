# نظام إدارة العيادة

نظام ERP متكامل للعيادات: باكند (Express + tRPC + Drizzle)، لوحة تحكم للأطباء والموظفين، وبوابة للمرضى.

## التشغيل السريع

```bash
npm install
cp .env.example .env
npm run db:migrate   # إنشاء جداول قاعدة البيانات
npm run db:seed      # إنشاء أول حساب مدير نظام
npm run dev          # يشغّل الخادم (4000) والواجهة (5173) معًا
```

افتح المتصفح على `http://localhost:5173`

**بيانات دخول المدير الافتراضية** (غيّرها فورًا من الإعدادات بعد أول دخول):
- البريد: `admin@clinic.com`
- كلمة المرور: `admin12345`

## خطوات الإعداد الأولى بعد التشغيل

1. سجّل دخول كمدير نظام بالبيانات أعلاه
2. من صفحة **الإعدادات** أنشئ حساب طبيب (حدّد التخصص وسعر الكشفية) وحساب موظف استقبال
3. سجّل خروج، وادخل بحساب الطبيب من صفحة **الإعدادات** لإضافة جدول دوامه (الأيام والأوقات)
4. أي شخص يمكنه الآن فتح `http://localhost:5173` والضغط على "مريض جديد؟ أنشئ حسابًا" لتسجيل حساب مريض وحجز موعد فعلي

## البنية

```
clinic-erp/
├── client/          # واجهة React (لوحة التحكم + بوابة المريض)
│   └── src/
│       ├── pages/admin/     # صفحات الطبيب والموظفين
│       ├── pages/patient/   # صفحات المريض
│       └── components/      # مكونات مشتركة + مكتبة تصميم (Card, Button...)
├── server/          # الخادم Express + tRPC
│   ├── routers/     # auth, appointments, patients, consultations, invoices, admin
│   └── _core/        # الإعدادات، السياق، المصادقة
├── drizzle/         # مخطط قاعدة البيانات والهجرات
└── shared/          # ثوابت وأنواع مشتركة بين الخادم والواجهة
```

## الحسابات والأدوار

| الدور | الصلاحيات |
|---|---|
| `admin` | كل الصلاحيات، بما فيها إنشاء حسابات الأطباء/الموظفين |
| `doctor` | الطابور، الفحص والتشخيص، الوصفات، التقارير، جدول دوامه |
| `staff` | المواعيد، تسجيل الوصول، الفواتير والمدفوعات |
| `patient` | حجز المواعيد، ملفه الطبي، تقاريره، فواتيره |

## قاعدة البيانات

تعمل افتراضيًا على **SQLite** محليًا بدون أي إعداد إضافي (ملف `drizzle/clinic.db`).

للانتقال إلى **MySQL/TiDB** بالإنتاج:
1. غيّر `DATABASE_DRIVER=mysql` و `DATABASE_URL` في `.env`
2. عدّل `server/db.ts` و`drizzle.config.ts` لاستخدام `drizzle-orm/mysql2` بدل `better-sqlite3` (نفس أسماء الجداول والأعمدة بالضبط، فالتحويل لا يمس منطق العمل)

## خدمات خارجية (اختيارية حاليًا)

النظام يعمل بالكامل محليًا بدون أي مفاتيح خارجية. عند توفر مفاتيح حقيقية لاحقًا:
- **OAuth** (بدل تسجيل الدخول بالبريد/كلمة المرور): فعّل `OAUTH_ENABLED` وأضف المفاتيح في `.env`
- **تخزين S3** (رفع صور/مرفقات التقارير): غيّر `STORAGE_DRIVER=s3` وأضف مفاتيح `S3_*`

## الأوامر المتاحة

```bash
npm run dev          # تشغيل الخادم والواجهة معًا (تطوير)
npm run build         # بناء نسخة الإنتاج
npm run start          # تشغيل نسخة الإنتاج المبنية
npm run db:generate    # توليد ملف هجرة جديد بعد تعديل drizzle/schema.ts
npm run db:migrate     # تطبيق الهجرات
npm run db:studio      # واجهة رسومية لتصفح قاعدة البيانات
npm run test            # تشغيل الاختبارات
```
